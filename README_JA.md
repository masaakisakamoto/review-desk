# Review Desk

画面を見ながら話したことを、画像付きの修正依頼にする小さなChrome拡張機能。

[English](README.md) · [既存版からの更新](docs/UPDATE_JA.md) · [検証結果](docs/VALIDATION.md) · [設計判断](docs/DESIGN.md)

[β版リリース説明](docs/RELEASE_NOTES_1.1.0-beta.3.md) · [架空の修正依頼例](examples/request/REQUEST.md) · [公開状況](docs/RELEASE_PREPARATION.md)

文字・画像・範囲を指定してコメントを残し、「要相談・修正確定・保留」を整理。人や各種AIへ渡せるZIPを書き出し、同じ指摘番号で修正後の確認まで追えます。アカウント登録とサーバー構築は不要です。

**1.1.0-beta.3：MITライセンスの公開β版ソースです。** 自動検証はChrome APIを模擬しています。この環境では実際のChromeへの導入・実タブ撮影を確認できていません。以前のMacで最初の読み込みが止まった原因も未特定です。打ち合わせへの利用・安定版化の前に[実機チェック](docs/MANUAL_CHROME_CHECKLIST.md)を行ってください。Web Storeには未申請です。β版の操作画面は日本語、README・導入説明・依頼文は日英に対応しています。

文字・リンク・画像に応じた操作案内と「続けて文字を指定」を追加しました。関連する操作の修正と検証範囲は[操作確認報告](docs/OPERATION_REVIEW_JA.md)にまとめています。

文字の番号を選択文字のそばへ配置し、スクロール・リサイズに追従させました。既存メモは文言が一意なら追従します。詳しくは[今回の修正](docs/TEXT_PIN_FIX.md)を参照してください。

## 新規導入

1. 解凍したフォルダを、今後移動しない場所に置きます。
2. パソコンのChromeで `chrome://extensions` を開き、デベロッパーモードをオン。
3. 「パッケージ化されていない拡張機能を読み込む」で `extension` フォルダを選びます。
4. 確認したいHTTP(S)のWebページを開き、Review Desk →「この画面でメモする」。
5. 「場所」でボタンや画像をクリック。「文字」で文章をドラッグ。「囲む」で範囲を指定。
6. メモを入力し、「端末に保存済み」を確認して判断を選びます。
7. 「一覧・修正依頼」で、決まった内容の書き出しや修正後の確認に進みます。

**既存の1.0.0／1.0.1を使っている方は、拡張機能を削除しないでください。** 保存済み記録を守るため、バックアップ後に[登録済みの場所を更新](docs/UPDATE_JA.md)します。

## 記録から修正後の確認まで

| 段階   | 操作                                                                                               |
| ------ | -------------------------------------------------------------------------------------------------- |
| 記録   | 対象を指定し、どう変えたいかを書く。自動保存を確認する。                                           |
| 判断   | 要相談・修正確定・保留を選ぶ。空の内容は確定できない。                                             |
| 依頼   | 「修正依頼を書き出す」。初期選択は「修正確定・未対応だけ」。共有する番号と画像の有無を確認する。   |
| 修正後 | 同じ指摘番号に修正後画像を添付し、対応内容・確認メモを書く。「確認待ち」から「確認済み」へ進める。 |

確認済みの要件・修正文・変更範囲を書き換えた場合は未対応に戻します。確認済みの後画像を差し替えた場合は確認待ちに戻します。確認済みにするには確認メモが必要です。確認者名と後画像は任意です。

案件名と役割は「案件・役割の設定」で変更できます。役割は記録のラベルで、対象サイトの権限を変更する機能ではありません。

## 書き出すもの

| ファイル              | 内容                                                                 |
| --------------------- | -------------------------------------------------------------------- |
| `REQUEST.md`          | 修正確定・未対応だけを実装対象にした依頼文。日英選択可。             |
| `MEETING_REVIEW.html` | オフラインで読める画像付き一覧。修正前後・確認結果も表示。           |
| `review-data.json`    | 指摘番号、安定ID、対象箇所、画面情報、判断、画像パス。               |
| `images/`             | 原画像・枠付き画像・参考画像・修正後画像。画像を含めない設定も可能。 |
| `backup.review.json`  | 今回書き出した記録を、別の打ち合わせとして復元するためのデータ。     |

「打ち合わせ全体」を選ぶと、相談・保留・確認済みも共有資料に含めます。依頼文の実装対象には入りません。ごみ箱はZIPに含みません。

ZIP作成は端末へのダウンロードです。外部に送るのは、そのファイルを利用者が渡すときだけです。**このZIPは必ずしも全件バックアップではありません。** 全記録とごみ箱の保存には、別の「バックアップ」ボタンを使ってください。

読み込みは新しい打ち合わせへの追加です。既存データを上書きせず、指摘番号と安定IDを維持します。ローカルDBのIDは衝突を避けるため再発行します。何度読み込んでも自動統合はしません。

## 架空のデモで試す

`examples/sample.review.json` を読み込むと、架空の展示サイトの指摘を確認できます。画像には模擬データであることを明記しています。`examples/meeting/MEETING_REVIEW.html` は拡張機能なしで読めます。

開発用Node環境があれば、`npm ci --ignore-scripts` の後に `npm run demo` を実行し、`http://127.0.0.1:8765/` を開きます。拡張機能をこの架空のサイトで起動すると、実際の撮影を試せます。

`extension/demo.html` の「操作練習」は**模擬撮影**です。Chrome APIの実動作確認にはなりません。HTTPで開いた場合はそのオリジンの保存領域、拡張機能内で開いた場合は拡張機能の保存領域に別のデモ案件を作ります。

## 保存と共有の仕組み

記録は、このChromeプロファイルのIndexedDBに保存します。外部通信、アクセス解析、AI API、クラウド同期、バックグラウンド送信はありません。必要な権限は手動で起動したタブへの一時アクセスとスクリプト注入です。

URLの資格情報・クエリ、一部の認証情報に見えるフラグメントを除去します。ただし、**URLのパス、通常のフラグメント、ページの文章、スクリーンショットには個人情報が残り得ます**。自動マスキング機能ではありません。添付画像のメタデータも自動除去しません。共有前に内容を確認してください。

拡張機能・Chromeプロファイルの削除、保存領域の消去や不足、端末の故障で記録を失う場合があります。暗号化・無期限保存の保証はありません。打ち合わせの区切りでバックアップしてください。[詳細](PRIVACY.md)

## 対応範囲と制限

- パソコンのChromeで普通のHTTP(S)ページを確認します。スマホ、Safari、Firefox、Chrome内部画面、Web Store、file URLは対象外です。Manifestの最小値110はAPI上の設定で、実機検証済みバージョンを示しません。
- 撮影は表示中の範囲です。全ページ撮影はしません。iframeや複雑な埋め込みは範囲指定を使います。iframe／Shadow DOM内部のセレクタ解決には対応しません。
- ページ移動・再読み込み後は起動し直します。他タブの変更はライブ反映されません。サイト側が先に登録したイベントによりクリック抑止が効かない場合があるため、削除・支払い等の実操作を試験対象にしないでください。
- 添付はPNG/JPEG/WebP、1枚8MBまで。書き出し時の描画は1枚40メガピクセルまで。書き出すデータは圧縮前100MiBまで、大量の記録は案件を分けてください。
- 同じメモの同時編集は古い上書きを止めます。失敗した入力はダウンロードして照合できますが、自動統合はしません。
- 修正後画像の添付と確認は手動です。履歴は判断・対応状況の直近200回までで、改ざん防止の監査ログではありません。
- 共同編集・音声動画・直接AI接続は未実装です。セレクタは対象の手がかりであり、ソースの特定や修正成功を保証しません。

## 検証・開発

Node 22以上、npm、Python 3.9以上を使用します。

```bash
npm ci --ignore-scripts
npm test
npm run check
npm run package
```

利用時のビルドは不要です。`extension/` が配布するコードそのものです。依存の固定、検証手順、未確認事項は[検証結果](docs/VALIDATION.md)に記載しています。自動テストは模擬Chrome API・DOM・IndexedDBと実際の画像エンコーダーを使用し、実機試験と区別します。
