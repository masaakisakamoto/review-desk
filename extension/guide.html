文字・画像・範囲を指定すると、画面とメモがこのChromeに残ります。外部へは自動送信しません。

架空の画面で操作を練習 記録を開く

練習画面の撮影は模擬画像です。実際のタブ撮影は、普通のWebページで拡張機能を起動して確認してください。

4つの操作

  1. 拡張機能 →「この画面でメモする」。準備が終わったら「場所」「文字」「囲む」で対象を指定。
  2. 短いメモを書き、「端末に保存済み」を確認。「要相談・修正確定・保留」を選択。
  3. 一覧の「修正依頼を書き出す」。共有する番号と言語・画像の有無を確認してZIPを保存。
  4. 同じ指摘番号に修正後画像と確認結果を残し、確認待ち → 確認済みへ。

Escで指定を中断。「見る」で通常のサイト操作に戻ります。画面の確認記録と、修正後の確認済みは別の記録です。

保存と更新

全件の保存は「バックアップ」。ごみ箱も含めます。読み込みは別の打ち合わせを作り、元の記録を保持します。旧版からの更新は登録済みのフォルダを同じ場所で置き換え、拡張機能IDを維持してください。削除して追加し直さないでください。

画像やURLのパスには画面に見える情報が含まれます。共有前に確認してください。拡張機能やプロファイルを削除するとデータを失う場合があります。

Quick guide

  1. Open the extension on an HTTP(S) page. Choose an element, selected text or a region.
  2. Write a note and wait for “端末に保存済み” (saved). Choose Discussion, Approved or On hold.
  3. Export only Approved + To do issues, or the full meeting. Pick English for the request packet.
  4. Attach an after image and record the result under the same issue code. Mark it verified after checking.

No account, telemetry, server or direct AI connection. Review data stays in this browser profile until you explicitly share an exported file. The practice page uses synthetic captures. This beta's real Chrome installation and capture remain unverified in the development environment.
