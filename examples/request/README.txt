Review Desk portable review packet

REQUEST.md — implementation scope (Approved + To do only)
MEETING_REVIEW.html — offline before/after and verification summary
review-data.json — structured target information and relative image paths
images/ — images, only if selected
backup.review.json — restore these exported records as a separate project

This packet is NOT necessarily a full backup. Trash is always excluded. A request-only packet contains only Approved + To do records. Use the separate Backup button for all records, including Trash. Screenshot and URL contents are not automatically redacted. No file in this ZIP sends data to a server.
