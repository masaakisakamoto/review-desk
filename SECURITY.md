# Security

This beta runs after a user invokes it on a page. It stores potentially sensitive screenshots and notes locally and exports them only on request. It is not a secret scanner or an encrypted vault. See PRIVACY.md.

Do not place sensitive reports, customer screenshots or credentials in public issues. Private vulnerability reporting is enabled for this repository. Use [Security → Advisories](https://github.com/masaakisakamoto/review-desk/security/advisories) and choose **Report a vulnerability**. GitHub sign-in is required. The reporting setting was verified on 2026-09-20; no test vulnerability report was submitted.

Use a synthetic page and minimal reproduction. Include extension/browser versions, the affected boundary and steps. No response-time or supported-version commitment is claimed for this beta.
