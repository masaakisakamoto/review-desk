はじめて使う

  1. このフォルダを今後移動しない場所へ保存。
  2. Chromeで chrome://extensions を開き、デベロッパーモードをオン。
  3. 「パッケージ化されていない拡張機能を読み込む」で、この中の extension フォルダを選択。
  4. 普通のWebページでReview Desk →「この画面でメモする」。

Start in Chrome

Keep this folder in a permanent location. Open chrome://extensions, enable Developer mode and load the extension directory. No build or server is needed. Existing users must update at the same registered path to retain their extension ID.

Real extension installation and live-tab capture have not been verified in this environment. Read the validation notes before using the beta in a meeting.
